# UX

## Кейсы

### Обработка текста in-place заранее определенным способом - реализовано

- Пользователь выделяет текст в стороннем приложении
- Нажимает на кнопку "Share"
- Выбирает Craftify из списка приложений
- Выбирает операцию
- Нажимает Paste в стороннем приложении

### Получение дополнительной информации заранее определенным способом - реализовано

- Пользователь выделяет объект в стороннем приложении
- Нажимает на кнопку "Share"
- Выбирает Craftify из списка приложений
- Выбирает операцию
- Нажимает Paste в стороннем приложении
