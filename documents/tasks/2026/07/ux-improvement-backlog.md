# UX Improvement Backlog — Wave 1 of 12 Researched Features [ANC:task:2026-07-ux-improvement-backlog]

## Goal

Reduce friction on Craftify's critical routes (share-extension processing, settings, onboarding). 12 user-selected UX improvements were researched in-code for feasibility, complexity, risk, and mutual compatibility; this task implements the first wave of 7 (features 20, 19, 17, 8, 10, 11, 13 — selected variant 3). Features 12, 15, 7, 4, 5 are deferred with reasons recorded under Follow-ups; the research record for them is preserved in Current State below.

## Overview

### Context

The user selected ideas 4, 5, 7, 8, 10, 11, 12, 13, 15, 17, 19, 20 from a generated list of 20 UX improvements. Six research subagents studied them against the codebase. Recommended dependency order: 20 → 19 → 17 → 8 → 10 → 11 → 13 → 12 → 15 → 7 → 4 → 5.

Cross-cutting blockers found by research:

- **F15 (history)**: the shipped privacy policy text (`privacy_policy_full`, 11 locales × 2 bundles) states the app "never stores" processed content. History MUST be opt-in and the policy text rewritten before any storage lands.
- **F4 (return to host)**: iOS host apps (Safari, Mail, Notes…) ignore `returningItems` from share extensions — the feature cannot work as "replace selected text". Only an honest, no-UI-promise variant is viable.
- **F7 (streaming)** must come after F19 (sheet height, result area designed for growing text) and F13 (model selection, avoids re-touching all 4 clients twice).
- **F12 (custom prompt)** is the right moment to add a stable `UUID` to `InventoryOperation` — one schema migration, also needed by F5 (App Intents).

Save point: `ShareExtensionManager.swift:132` (`self.lastResult = processedText`). Inject `HistoryManaging` into `ShareExtensionManager` (8 construction sites). Entry point: clock icon in `HomeView` toolbar.
- **F7 Streaming (L)** — add `stream()` to `LLMClienting` returning `AsyncThrowingStream<String, Error>`; shared SSE parser with OpenAI dialect (OpenAI/Mistral/OpenRouter, incl. keep-alive comments) and Anthropic dialect. Timeout redesign: first-token deadline 10–15s + idle timeout, retries only BEFORE first token. Fixes an existing cancellation leak. Result view must append tokens (F19's grown sheet is the canvas). Shares the "final text ready" point with F15's save.
- **F4 Return to host (S, honest-variant only)** — `extensionContext.completeRequest(returningItems:)` is implemented trivially, but Safari/Mail/Notes ignore returned items; no user-visible promise can be made. Recommend: skip, or ship silently without UI text.

Keyboard-extension alternative rejected (L, scary permissions).

Compatibility matrix: no mutual conflicts found; only ordering constraints (19 before 17 and 7; 13 before 7; 12's UUID before 5 ideally; 15's policy rewrite before any storage).

### Constraints

- `./run check` must stay green after every feature: strict SwiftLint (warnings as errors), Periphery dead-code scan, full test suite, gitleaks.
- All user-facing strings ship in 11 locales (bg, de, en, es, fr, it, ja, pt, ru, uk, zh-Hans) in the owning bundle — MainApp, ShareExtension, or Common (all three carry a full 11-locale `.lproj` set; verified by `ls src/Common/Resources/*.lproj` = 11).
- No new third-party dependencies; Apple frameworks only.
- Share extension memory ceiling (~120 MB) — history entries and streaming buffers must stay bounded.
- App Group storage schema changes (`InventoryOperation`, new history store) must decode tolerantly: unknown enum cases or fields must never wipe user data.
- Privacy policy text is a shipped legal artifact: F15 cannot merge before the policy rewrite lands in the same change.
