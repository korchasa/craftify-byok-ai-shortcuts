# План: Переработка GitHub Actions под новые тесты и ./run-команды

## Статус: выполнено
- Workflow теперь использует ./run test для всех проверок (lint, format, unit, E2E).
- Проверка размера Share Extension через ./run check-size.
- Coverage собирается через xccov после тестов.
- Кэшируются Mint, SwiftPM, DerivedData.
- Артефакты coverage и build-logs загружаются.
- Workflow падает при ошибках тестов, линтинга, форматирования, покрытии <80% или превышении размера extension.

## Запрос пользователя
Переработать GitHub Actions с учетом переделки тестов. Использовать команды из ./run.

## Анализ
- В проекте все тесты (unit, UI, E2E) запускаются через ./run test, который сам вызывает линтинг, форматирование, unit и E2E тесты для всех модулей.
- В документации и roadmap указано: обязательное покрытие ≥80%, автоматическая проверка размера Share Extension (≤20MB), все ключевые сценарии покрыты E2E тестами.
- В текущем workflow команды xcodebuild, swiftlint, swiftformat вызываются напрямую, а не через ./run.
- Для DevOps-friendly подхода и единообразия нужно запускать тесты, линтинг и форматирование через ./run test (он сам вызывает все нужные проверки).
- Проверку размера Share Extension и coverage также можно реализовать через ./run (или отдельные команды, если потребуется).
- Кэширование Mint, SwiftPM, DerivedData — оставить для ускорения.
- Все артефакты (coverage, build-logs) должны загружаться как раньше.

## Подзадачи
1. Перевести все проверки (lint, format, test) на вызов ./run test.
2. Проверку размера Share Extension вынести в отдельный шаг через ./run check-size.
3. Проверку покрытия реализовать через coverage-отчет (оставить xccov, но запускать после ./run test).
4. Сохранять артефакты coverage и build-logs.
5. Оставить кэширование Mint, SwiftPM, DerivedData.
6. Убедиться, что workflow падает при ошибках линтинга, форматирования, тестов, покрытии <80% или превышении размера extension.
7. Обновить документацию по CI/CD при необходимости.

## Возможные проблемы и решения
- Mint может не быть установлен на runner: добавить установку через brew.
- ./run должен быть исполняемым (chmod +x).
- Если coverage-отчет не формируется — добавить явный вызов xccov после ./run test.
- Если размер extension не проверяется — убедиться, что ./run check-size работает и возвращает exit 1 при превышении лимита.

## Итоговый workflow
- Checkout + кэширование
- Установка Mint и зависимостей
- Проверка ./run на исполняемость
- ./run test (unit, UI, E2E, lint, format)
- coverage-отчет (xccov)
- ./run check-size
- upload artifacts
- fail при ошибках
