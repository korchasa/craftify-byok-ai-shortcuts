# Задача: Приветственный экран до согласия пользователя

## Запрос
Показывать приветственный экран, пока пользователь не согласится с условиями.

## Анализ
- В проекте уже реализован экран HowToUseView с чекбоксом согласия и менеджером ConsentManager.
- Сейчас приложение всегда стартует с HomeView.
- Необходимо:
  1. Сделать глобальное состояние (например, AppState) с Published-флагом согласия.
  2. В CraftifyApp показывать HowToUseView, если согласие не получено, иначе HomeView.
  3. После согласия автоматически переходить на HomeView.
  4. Покрыть логику e2e-тестом (flow: нет согласия → согласие → переход на HomeView).
- Потенциальные сложности: корректная реакция на изменение согласия, отсутствие race condition, тестируемость.

## План
1. Добавить AppState (ObservableObject) с Published-флагом согласия.
2. В CraftifyApp использовать AppState через @StateObject.
3. В зависимости от appState.isConsentGiven показывать HowToUseView или HomeView.
4. В HowToUseView добавить callback onConsent, который будет вызываться после согласия.
5. В e2e-тестах проверить переход с приветственного экрана на основной.
6. Проверить, что согласие сохраняется и после перезапуска приложения показывается HomeView.
7. Обновить документацию (architecture.md, implementation.md, user-manual.md).
