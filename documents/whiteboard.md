## Обновление ShareExtensionViewModel

### Решенные проблемы
1. **Асинхронная загрузка данных**: исправлено отображение операций при асинхронной загрузке URL
2. **Улучшенное логирование**: добавлено отображение первых 100 символов входного текста в логах
3. **Рефакторинг**: выделены повторяющиеся части кода в отдельные методы
4. **Тестирование**: обновлены существующие тесты и добавлены новые для проверки функциональности

### Технические детали
- ShareExtensionViewModel теперь фильтрует операции в методе `updateInputText()` вместо конструктора
- Добавлено обширное логирование на всех этапах обработки данных
- Код разбит на небольшие методы с четкой ответственностью
- Тесты подтверждают корректную работу с URL и обычным текстом
