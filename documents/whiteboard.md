# План: Внутренний контейнер (bottom sheet) для Share Extension

## 1. Переформулировка задачи
- Требуется реализовать внутренний контейнер (bottom sheet), который визуально ограничивает рабочую область Share Extension, даже если само окно открывается на весь экран.
- Контейнер должен выглядеть как отдельная карточка/панель с закруглёнными углами, тенью и отступами от краёв экрана.
- Весь остальной фон должен быть полупрозрачным или повторять системный background.

## 2. Анализ и требования
- Контейнер должен быть центрирован по горизонтали и прижат к нижнему краю (или с небольшим отступом).
- Высота контейнера — фиксированная или вычисляемая (например, 300–400pt), но может занимать до 100% высоты окна, если операций много.
- Контейнер всегда не больше родительского окна (использовать .maxHeight = .infinity, .frame(maxHeight: .infinity, alignment: .bottom)).
- Контейнер должен поддерживать safe area (не залезать на Dynamic Island, Home Indicator и т.д.).
- Весь основной UI (заголовок, кнопки, операции) переносится внутрь контейнера.
- Остальная часть экрана не интерактивна. При клике вне контейнера — отменять шаринг и закрывать окно.
- Должна быть поддержка тёмной темы.

## 3. Подзадачи
1. Создать компонент BottomSheetContainerView (SwiftUI View):
    - Card-style view с закруглёнными углами, тенью, отступами.
    - Принимает content как @ViewBuilder.
2. Внедрить BottomSheetContainerView в ShareExtensionView:
    - Вынести весь основной UI внутрь контейнера.
    - Внешний ZStack — фон (Color(.systemBackground).opacity(0.7) или blur).
    - Добавить прозрачную кнопку-оверлей вне контейнера для обработки клика (закрытие окна).
3. Обновить layout:
    - Контейнер центрируется по горизонтали, снизу safe area (или с отступом).
    - Высота — фиксированная или вычисляется по количеству операций, но не больше высоты окна.
4. Добавить поддержку жеста закрытия:
    - Клик вне контейнера отменяет шаринг и закрывает extension.
5. Обновить стили (тень, скругления, фон, поддержка dark mode).
6. Покрыть изменения snapshot- и e2e-тестами.
7. Обновить документацию (архитектура, имплементация, user manual).

## 4. Возможные проблемы и решения
- **Проблема:** Контейнер может перекрывать системные элементы (Dynamic Island, Home Indicator).
  - **Решение:** Использовать safeAreaInsets и .padding(.bottom, ...).
- **Проблема:** Клик вне контейнера не закрывает extension.
  - **Решение:** Добавить прозрачную кнопку-оверлей, которая вызывает отмену и закрытие.
- **Проблема:** Высота контента больше контейнера.
  - **Решение:** ScrollView внутри контейнера.
