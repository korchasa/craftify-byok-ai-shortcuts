# [2024-06-09] Исправление обработки URL для операций

## Проблема
- В summarize url отправлялся напрямую в LLM, а не преобразовывался в текст.
- Не было единого способа для операций обрабатывать url/text.

## Решение
- В протокол OperationType добавлен асинхронный метод resolveInput.
- Для SummarizeOperation: поддержка url (загрузка и парсинг текста).
- Для остальных операций: только text, url вызывает ошибку.
- ViewModel всегда вызывает resolveInput перед отправкой текста в LLM.
- Теперь url не отправляется напрямую в LLM.
